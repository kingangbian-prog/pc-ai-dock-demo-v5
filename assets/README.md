# 壁纸素材

`wallpaper.png` 由本任务使用内置 Image Gen 生成，生成后复制到项目内，运行时完全本地加载。

提示词：

> Use case: stylized-concept. Asset type: standalone 16:9 PC operating system wallpaper, 2560x1440 style, no UI, no text, no logos. Primary request: a refined, immersive blue glass desktop wallpaper. Abstract sweeping translucent layered glass ribbons and soft satin surfaces, in deep marine blue, pale frosted ice, muted slate and a subtle touch of cobalt. An elegant luminous curved crest enters from the right and curves toward the lower left; dark quiet blue negative space on the left and upper left so light desktop windows remain legible. High-end native desktop wallpaper, calm depth, very smooth tonal transitions, crisp subtle edges, soft natural studio light. No neon, no stars, no grid, no futuristic HUD, no lettering.

界面文字、图标、窗口、表单和状态由代码原生渲染，壁纸不包含交互 UI。
