## 运行

Node.js 20+，无需安装依赖。`npm start` → http://127.0.0.1:4175/ 。`npm run check` 检查模块语法，`npm test` 运行状态及交互控制器测试。

## 体验

1. 新版本默认为晾衣架样式，并展开实况。菜单栏中央“AI 实况”入口再次点击或 Esc 收起。菜单栏最右侧按钮切换胶囊/晾衣架；刷新保留样式偏好。
2. 细绳下的独立玻璃卡显示真实模拟任务状态、当前步骤和操作。数量多时可使用左右按钮、横向滚动或键盘浏览；删除后数量少于可视宽度时剩余卡重新居中。
3. 卡片右上角叉号只隐藏实况展示，不取消任务、不删除文档或历史、不改变授权及 Computer 控制权。顶部“恢复已隐藏”可恢复；全部隐藏时显示空状态。隐藏偏好同时作用于两种样式。
4. 隐藏以“任务当前状态/输出版本”为范围；普通进度文字刷新不反复冒出，但状态变化或产生新输出后该任务可重新显示。任务仍可通过 Bot、Agent 和通知访问。
5. 每张卡可发送该任务的补充。两种样式共享未发送草稿。补充不代表授权，不自动重试或恢复。待确认卡进入原授权流程，失败卡可重试，结果卡打开原任务的输出文档，Computer 卡查看同一会话。
6. Dock 的 Liquid Glass 使用多层透明、模糊、亮边及轻微指针光点；保留单行、溢出滚动、开始菜单临时运行图标和最后窗口关闭移除。CSS 视觉模拟，不是原生系统材质或物理折射引擎。
7. Bot 保留指定长标题、Goals/Connect 独立折叠、Ideas 四个子节点、通知、任务/文档归属与关闭生命周期、Computer 接管 ACK、未保存保护、交还流程以及双模式壁纸文案。点击 Bot 或打开应用收起顶部卡片，便于操作窗口。

## 数据隔离

v3 只读写 `ai-dock-prototype-v5`，不读取或迁移 v1/v2 的保存键。不同 Pages 路径共享同一域也不会串用。刷新保留任务、草稿、样式和隐藏偏好；打开的窗口布局与未发送补充属于当前页面状态。Demo 5 首次打开不自动弹出 Bot/文稿窗口，可从 Dock 打开。
